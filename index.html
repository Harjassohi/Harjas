LATEST · Microsoft Fabric · synthetic data

Real-Time Contact Centre Monitoring on Fabric

Warehouse · T-SQL · Power BI · Fabric Data Agent · Copilot Studio

A rebuild of my Excel, Access and VBA performance report on Microsoft Fabric. Raw contact-centre dumps load through pipelines, are transformed in SQL and feed one semantic model. Users can ask questions of the data or change a forecast through chat, and the change appears in the report.

CSV / API dumps→Lakehouse→Warehouse (T-SQL)→Semantic model→Power BI
Copilot Studio→SQL database + stored procedure→Pipeline sync→Warehouse→Report
  • Report: service level, abandon rate, forecast vs offered, CSAT and agent productivity by interval, with heat-map matrices.
  • Data Agent (read-only): answers questions on top of the semantic model.
  • Copilot Studio agent (write-back): saves planned-number overrides through a stored procedure with validation and an audit trail.
  • Pipelines: sync overrides, then refresh the semantic model on a schedule.
  • Planned: row-level security by team leader, so each leader sees only their own team.

All data shown is synthetic.

Production · Telecom contact centre

Hourly Performance Report: Excel, Access, VBA and Power Pivot

Excel · MS Access · VBA · Power Pivot · Cisco dumps · Reliance Jio

The original report that the Fabric project rebuilds. I designed and ran it for a large telecom contact centre. Two raw dumps went in: Cisco service-level data by call queue and 30-minute interval, and an agent productivity dump. One workbook came out with views for every level of the operation.

What it covered

  • Service level (80/20 and 90/60), abandon rate, offered and answered vs forecast
  • Interval views by queue (mobility, fibre) and by circle
  • A regulator service-level view by interval and circle
  • Line-of-business view by dialled number: offered, answered, SL, abandon, AHT, hold, ACW, ASA

And behind the scenes

  • Advisor productivity: calls, AHT, talk, hold, ACW, not-ready, staffed hours, planned AUX and breaks
  • Shrinkage: scheduled vs present vs planned leave by interval
  • Forecast, capacity and planned AUX inputs
  • A glossary giving every field's source and definition

The report refreshed with VBA and Power Pivot, visualised the trends and emailed them to operations leaders. 10 GB of trends refreshed and emailed in 10 minutes.
