NZ Economy — Housing, Labour, OCR & Inflation

Fabric Lakehouse → SQL Views → Power BI · RBNZ + MBIE

Power BI analysis published on LinkedIn, built on a Fabric Lakehouse → SQL Views → Semantic Model → Power BI pipeline. Key findings:

  • From June 2023, the labour market is relying less on housing — new economic pathways opening.
